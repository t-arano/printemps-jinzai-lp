こんなときの採用相談に

詳しくないから、相談できないと思っていませんか。

  • 社内に外国人採用を経験した担当者がいない。
  • 専門的な言葉が多く、調べるだけで止まっている。
  • 自社のどの仕事を相談できるか分からない。

✓

✓

採用の予定

必要人数と希望時期を、未定の部分も含めて伝える。

SELECTくんで、検討の一歩を

最初に必要なのは、自社の仕事の説明です。

制度をすべて理解してから問い合わせる必要はありません。まずは、現場でどのような作業をしているか、どこで働くか、何人迎えたいかを教えてください。仕事内容と条件を確認したうえで、候補者の情報を見る段階へ。分からないことは分けて整理し、一度に採用の結論を出そうとしなくても大丈夫です。

ご相談の前に

気になることを、先に確認。

外国人採用の経験がなくても利用できますか？

初めて検討する企業様もご相談いただけます。自社の仕事内容と採用希望をお知らせください。対象業務や候補者の条件を個別に確認します。

制度のことを全部調べてから相談すべきですか？

まずは分かる範囲で仕事内容や勤務地をお伝えください。必要な手続きや費用は採用条件に応じて確認し、未定の事項も整理していきます。

手続きの費用も採用費に含まれていますか？

内定後の採用費は1人20万円（税別）です。VISA申請・登録支援などの費用は含まれず、別途必要になります。
